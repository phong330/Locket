# phong330 — Shadowrocket & Locket

## 🚀 Cài nhanh trên iPhone

### [👉 MỞ TRANG CÀI ĐẶT PHONG330](https://phong330.github.io/Locket/)

Mở trang bằng **Safari trên iPhone**, sau đó chọn nút cài cấu hình Shadowrocket. Trang web cần được bật tại **GitHub → Settings → Pages → main / (root)** và triển khai thành công.

### [🚀 Thử mở trực tiếp trong Shadowrocket](shadowrocket://config/add/https://raw.githubusercontent.com/phong330/Locket/main/phong330.conf)

> Một số trình duyệt, bao gồm trang GitHub, có thể chặn link `shadowrocket://`. Nếu không mở được, dùng trang cài đặt ở trên hoặc nhập link Raw thủ công trong Shadowrocket.

## Liên kết dự phòng

- **Cấu hình Shadowrocket:** [phong330.conf](https://raw.githubusercontent.com/phong330/Locket/main/phong330.conf)
- **Module (tùy chọn):** [phong330.sgmodule](https://raw.githubusercontent.com/phong330/Locket/main/phong330.sgmodule)
- **Hồ sơ DNS iPhone:** [LocketGold.mobileconfig](https://raw.githubusercontent.com/phong330/Locket/main/assets/LocketGold.mobileconfig)

Nếu đã dùng cấu hình chính có các script tương tự, không cần bật thêm module để tránh trùng quy tắc.

DNS dùng máy chủ bên thứ ba trong hồ sơ gốc, không bảo đảm hoạt động hoặc mở khóa Locket Gold. iOS yêu cầu người dùng tự xác nhận cài hồ sơ.
