## Lưu ý

- Cần bật GitHub Pages cho nhánh `main`, thư mục `/(root)`.
- Khi cập nhật `index.html`, trang có thể bị lưu cache. Thử tải lại hoặc mở cửa sổ riêng tư.
- Một số script và quy tắc trong dự án dựa trên mã nguồn bên thứ ba; hãy giữ các ghi nhận bản quyền và kiểm tra an toàn trước khi bật MITM.
- Hồ sơ DNS có thể dùng nhà cung cấp bên thứ ba; việc tải hồ sơ không có nghĩa là DNS hoạt động hay cấp quyền thuê bao Locket Gold.
