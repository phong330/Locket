ℹ️ Mở trang này bằng Safari trên iPhone. iOS có thể yêu cầu xác nhận trước khi mở Shadowrocket hoặc tải hồ sơ cấu hình. GitHub Raw có thể tải file DNS thay vì hiển thị lời nhắc cài hồ sơ.
